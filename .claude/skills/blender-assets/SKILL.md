# Blender 5.2 asset pipeline (headless, scripted)

All assets are **generated by Python scripts** under `blender/<area>/` so they are reproducible.
Run: `tools/blender_run.sh blender/<area>/build_x.py` (Cycles CPU; no GPU). Import helpers:
```python
import sys, os
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "lib"))
import common as C   # reset_scene, box, collision_box, smart_uv, uv_cube_project, principled,
                     # image_material, bake_maps, export_glb, preview_render, asset_path, qa_path
```
Read `blender/lib/common.py` first. Put your own helpers in `blender/lib/<area>_*.py`.
You may also save the source `.blend` next to your script (`blender/<area>/*.blend`, < 40 MB) for humans.

## Blender 5.x API changes that bite (verified on 5.2.3)
- `Material.use_nodes` is deprecated — materials always have `node_tree`. Find the BSDF by
  `bl_idname == "ShaderNodeBsdfPrincipled"`.
- Principled BSDF inputs: "Base Color", "Metallic", "Roughness", "IOR", "Alpha", "Normal",
  "Subsurface Weight", "Subsurface Radius", "Subsurface Scale", "Specular IOR Level", "Coat Weight",
  "Coat Roughness", "Sheen Weight", "Sheen Roughness", "Emission Color", "Emission Strength",
  "Transmission Weight". Print `[i.name for i in bsdf.inputs]` if unsure.
- Auto-smooth is gone: use `bpy.ops.object.shade_smooth_by_angle(angle=…)` (see `C.shade_smooth`) or a
  "Smooth by Angle" modifier; Weighted Normal modifier for hard-surface props.
- **Actions are slotted/layered**: `Action.fcurves` no longer exists. Author animation by setting
  `obj.animation_data.action = act` then posing and calling `pose_bone.keyframe_insert("rotation_quaternion", frame=f)`.
  For direct fcurve access: `act.layers[0].strips[0].channelbag(act.slots[0]).fcurves`.
  Each Action exports as one Godot animation with `export_glb(..., animations=True)`
  (`export_animation_mode="ACTIONS"`). Set `act.use_fake_user = True`, `act.use_frame_range = True`,
  `act.frame_start/frame_end`. Clear `animation_data.action = None` before export. Verified to import in Godot 4.7.
- Render engine ids: `"CYCLES"`, `"BLENDER_EEVEE"`. Use Cycles CPU (EEVEE ≈ 40 s for a 320×240 frame here).
- Baking: `C.bake_maps(obj, out_prefix, size, maps=(…))`. GENERATED images regenerate blank when re-used
  in-session, so bake_maps removes them; always re-load the saved files (`C.image_material`).
  High→low bake: select high, active low, `scene.render.bake.use_selected_to_active = True`, `cage_extrusion`.

## Quality bar ("photoreal game asset", not "programmer art")
Every asset must pass this checklist before you call it done (render a preview and LOOK):
1. **Real proportions** — model from real measurements (write them as constants at the top of the script).
2. **No perfect primitives** — bevel all hard edges (2–3 segments, `harden_normals`), break silhouettes
   (chips, sag, slight lean, irregular spacing), avoid perfectly flat large faces (subtle displacement/noise).
3. **Material layering** — base material + variation (noise-driven hue/value shifts), edge wear (curvature or
   bevel-based), cavity dirt/AO, grime streaks under windows/AC units, water stains, rust on metal,
   dust on upward faces. Roughness must vary — never one constant value for a whole surface.
4. **Micro detail in normals** — pores in plaster, brick mortar depth, wood grain, fabric weave, scratches.
5. **Colour realism** — albedo in physically plausible ranges (no pure black < 0.03 or pure white > 0.9
   except paint/emissive); use reference palettes of Hanoi/Saigon old quarters: ochre-yellow colonial
   plaster (#d9a441-ish faded), teal/green wooden shutters, terracotta roof tiles, weathered concrete,
   blue/red plastic stools, rusted corrugated iron, tangled black cables, bougainvillea magenta.
6. **Storytelling detail** — signage, potted plants, laundry, padlocks, stickers, cracked tiles, posters.
7. **Game-readiness** — clean UVs (no stretching, ≥ target texel density), triangle budget respected,
   colliders (`*-colonly`) simplified, origin & facing per CLAUDE.md, applied transforms, ≤ 2–3 materials
   per prop, textures packed (ORM) where possible.
8. **Validate in Godot** — copy is not needed: export into `assets/…`, run `tools/godot_import.sh`, then
   `tools/validate.sh "" assets/models/<area>` and a Godot screenshot of a test scene to confirm
   materials/normals/scale look right in-engine (normal-map green channel, sRGB vs linear).

Previews: `C.preview_render(C.qa_path("<area>/x.png"), target=…, distance=…)` (Cycles, denoised, AgX).
For hero shots you may add Cycles hair curves (fur) — those are preview-only; Godot uses shell fur.
